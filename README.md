# Reminder
Tkinter ile yapılmış hatırlatıcı uygulaması. Hatırlatma ekleme, listeleme, silme ve arama özellikleri sunar. Listeleme yaparken queue mantığına göre listeler. Belirlenen saatte masaüstü bildirimi verir. Ana ekranda dijital saat bulunur. Kullanıcı dostu ve koyu tema tasarımıyla hazırlanmıştır.
